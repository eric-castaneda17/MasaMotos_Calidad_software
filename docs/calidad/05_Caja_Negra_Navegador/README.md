# Caja negra manual de MASA MOTOS

## Preparación y registro

Abra la aplicación local en el navegador y fije el idioma en español. Verifique con la persona que administra las pruebas que la aplicación apunta al proyecto Supabase académico autorizado y que el lote en `.qa/lote.json` está vigente. El archivo registra referencias, nombres y saldos iniciales. Use la interfaz para todas las comprobaciones. Prepare una ventana separada para invitado y separe las sesiones de administrador y vendedor. Introduzca las credenciales directamente en el navegador y evite que aparezcan en capturas o trazas.

Arranque la compilación con `npm run start -- --hostname localhost --port 3106` y use `http://localhost:3106`. En la instancia probada con `127.0.0.1` se observó un bucle de redirección. Para filtrar referencias del lote que tienen guion bajo, use el fragmento distintivo sin guiones bajos y confirme por la referencia completa que aparece en la fila. Para BB-12, prepare una cuenta de prueba con una contraseña indicada en el entorno privado `QA_INACTIVE_PASSWORD` y ejecute `node scripts/qa-fixtures.mjs inactive` desde la terminal de preparación. El paso de caja negra se efectúa luego en el navegador.

Al terminar cada caso, complete **Resultado obtenido**, **Estado**, **Fecha**, **Evidencia**, **Defectos** y **Re-test** en la hoja Caja negra de la matriz. Guardar las imágenes con el ID del caso en esta carpeta. Ejemplo de nombre `BB-09-02-stock.png`. Si falta un dato o un permiso, conserve PENDIENTE y anote el impedimento. Cada captura debe mostrar solo lo que se necesita para verificar el paso.
